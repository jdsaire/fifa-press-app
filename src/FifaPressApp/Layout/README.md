# Layout/

Holds the parts of the screen that stay the same no matter which page you're on — the surrounding frame the actual page content appears inside of, rather than the content itself.

- **`MainLayout.razor`** — the overall page frame: a sidebar on one side, the current page's content on the other. Every page in this app gets displayed inside this same frame, and it's also where the language cascade starts — see `Components/LocaleProvider.razor` — so every page and every component below it can read the active language.
- **`MainLayout.razor.css`** — styling that applies only to `MainLayout.razor`, and nothing else in the app. This file-pairing pattern (a `.razor` file plus a matching `.razor.css` file with the same name) is called **CSS isolation** — see [`learning-mode/Glossary.md`](../../../learning-mode/Glossary.md#css-isolation) — and it means changing this file's styles can't accidentally affect some unrelated part of the app.
- **`NavMenu.razor`** — the sidebar: the "FIFA Press App" brand and a nav list of four or five rows, all of them destinations (Home, Matches, Help, Settings, plus My Requests once you're signed in). It used to end in a tail of controls — language, theme, sign out — housed there because the list is the same element at both breakpoints and a row added to it collapses on a phone for free. Those three have homes of their own now (`Pages/Settings.razor` and `SessionBar.razor`), so the tail is gone and the list is what it always said it should be: places you can go, and nothing else.
- **`NavMenu.razor.css`** — styling private to `NavMenu.razor` alone, following the same CSS-isolation pattern.
- **`SessionBar.razor`** — the row above the content column that names who is signed in, on every screen. It holds the holder's name and credential number, and a way out; signed out, it holds one way in. This is where the sidebar's session indicator went, and the move is the point: a sidebar collapses on a phone, so the one place "which record am I looking at" was hardest to answer was the one place nothing answered it. It is text rather than a link — a statement of fact, not a door.

This is a separate folder from `Pages/` because layout and page content answer different questions: `Layout/` answers "what surrounds every page," while `Pages/` answers "what's actually different about this one page." Keeping them apart means changing the sidebar once here updates it everywhere, instead of needing the same edit repeated on every individual page.
