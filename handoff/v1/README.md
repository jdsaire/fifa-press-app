# v1 — Original Build

The first build of this repository — then named EventEase, later adapted into the FIFA Press App without touching a line of this build's code: a working Blazor WebAssembly project from scratch, built as three approved gates matching the capstone's three graded Activities (Foundation, Debug & Optimize, Expansion), followed by the first pass at project documentation.

- [`Plan-C4EventEaseBuild.md`](Plan-C4EventEaseBuild.md) — the plan approved before this run started: repo state, file tree, commit sequence, verification steps.
- [`c4-eventease-build-completion-report.md`](c4-eventease-build-completion-report.md) — what actually happened: commit list, PASS/FAIL results, approved deviations, open items carried forward.

Everything built in v1 still exists in the app today — v2 (see [`../v2/`](../v2/)) added documentation, accessibility, and a live deployment on top of it, without changing how the app itself behaves.
